FASTA, FASTQ e SRA

Compreender a estrutura dos dados brutos de sequenciamento e obter uma fração real dos reads de Hypochilus depositados no SRA.

Esta aula inicia o pipeline principal de Hypochilus; não depende do BLAST.

O notebook começa mostrando o diretório atual, os caminhos usados e se o arquivo obrigatório da etapa anterior foi encontrado. Se faltar uma entrada, a execução é interrompida com uma mensagem clara.

Objetivos

  • distinguir FASTA e FASTQ;
  • compreender a organização do Sequence Read Archive (SRA);
  • reconhecer BioProject, BioSample, Experiment e Run;
  • baixar uma fração de reads paired-end do nosso dataset de Hypochilus;
  • inspecionar R1 e R2 e contar reads.

Importante: um Run do SRA representa dados de sequenciamento associados a um experimento. O accession SRR15736591 será nosso ponto de entrada para os reads brutos.

3. O que significa paired-end?

O mesmo fragmento de biblioteca é lido a partir de suas duas extremidades. Por isso, os dados são organizados em pares, normalmente chamados R1 e R2.

fragmento → R1 ←────────→ R2

4. Prática guiada no Colab

  1. consultar o run SRR15736591 e revisar seus metadados;
  2. instalar SRA Toolkit;
  3. baixar uma fração didática dos reads, evitando transferir o conjunto inteiro;
  4. gerar arquivos paired-end R1 e R2;
  5. compactar os FASTQ com gzip;
  6. visualizar os primeiros registros;
  7. contar o número de reads;
  8. salvar tudo no Google Drive para reutilização nas práticas seguintes.
Escala didática: o notebook usa inicialmente 200.000 spots. O valor pode ser reduzido em conexões lentas ou aumentado quando precisarmos recuperar mais UCEs.
