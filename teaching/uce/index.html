UCE Phylogenomics & Population Genomics

A step-by-step computational tutorial for processing Ultraconserved Element (UCE) target-capture data from raw sequencing reads to phylogenomic and population genomic analyses. The workflow is designed to be portable and adaptable to different datasets by changing only input paths, sample information, probe files and a small number of biological parameters.

Starting point

This tutorial assumes paired-end Illumina sequencing reads in compressed FASTQ format.

Tutorial design

Each module will explain the biological objective, required input files, software, commands, parameters, expected outputs, quality-control checks and common problems. Commands will use portable paths and will not depend on a specific institutional computing environment.
